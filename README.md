# OENOD

One connected platform and AI Business Manager for running a business: people, time, scheduling,
payroll, sales, point of sale, projects, fleet, marketing and more, with a public Jobs marketplace,
the OENOD Academy, a business directory, a public API and a plugin marketplace.

| Folder | What it is |
| --- | --- |
| `apps/web` | The website, the web app, the super admin console and the API (Next.js + PostgreSQL) |
| `apps/mobile` | iOS and Android app for employees (Expo) |
| `apps/desktop` | Windows, Mac and Linux app (Electron) |
| `packages/i18n` | Translations shared by all three (10 languages, including Arabic right-to-left) |

All three apps use the same server and the same database.

Start with **[docs/INSTALL.md](docs/INSTALL.md)**. The mobile and desktop apps have their own guides in their folders.
